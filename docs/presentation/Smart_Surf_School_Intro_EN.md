# Smart Surf School Management System

Open-source operations software for surf schools  
MIT License · English and Turkish

---

## One operational workspace

- Students, instructors and guardians
- Courses, sessions and attendance
- Equipment rental and maintenance
- Safety, weather and incident records
- Payments, reports and optional AI assistance

---

## Safe first start

1. Install locally and run the database migrations.
2. Run `python manage.py bootstrap_admin`.
3. Sign in on the host computer with `admin` / `admin`.
4. Replace the temporary password immediately.

Cloud AI is opt-in; the default mode is local-only.
